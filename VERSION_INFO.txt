🚀 QUICK START
═══════════════════════════════════════════════════════════════

Windows (Easiest):
  1. Double-click run_v1.bat
  2. Wait for setup (~1-2 minutes)
  3. Application starts automatically

Manual Setup:
  1. python -m venv venv
  2. venv\Scripts\activate
  3. pip install -r requirements_v1.txt
  4. python main_v1_complete.py
