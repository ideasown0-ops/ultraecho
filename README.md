# AI Ultrasound Assistant V1.0

Enhanced AI-powered ultrasound analysis system with advanced diagnosis capabilities.

## Features

- 🎥 Live capture from ultrasound devices
- 📹 Recorded video analysis
- 🏥 Enhanced diagnosis with pathology detection
- 📊 Medical report generation
- 💾 SQLite database
- 🖥️ PySide6 GUI

## Installation

```bash
pip install -r requirements_v1.txt
python main_window_v1.py
```

## Usage

1. Open Live Capture or Recorded Video tab
2. Capture frame or play video
3. Click "Analysis Report" button
4. View results in AI Analysis tab

## System Requirements

- Python 3.12+
- Windows 10/11
- 4GB RAM (8GB recommended)
